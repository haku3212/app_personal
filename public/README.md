# Recursos estáticos

Coloca aquí el ícono de la aplicación para el instalador de Windows:

- `icon.ico` — ícono multi-resolución (256×256 recomendado).

`electron-builder` lo usa automáticamente (configurado en `package.json → build.win.icon`).
Si no existe, electron-builder usa el ícono por defecto de Electron.
